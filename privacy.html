橘子 · 隐私政策

生效日期：2026 年 11 月 22 日　｜　版本 1.1.3　｜　适用于“橘子”Android 应用及配套学习站

“橘子”是一个为四川专升本计算机基础备考准备的学习工具。我们把数据分成两类：一类只留在你的手机上；另一类只有在你主动登录账号、使用云同步、提交反馈或使用 AI 答疑时，才会传输到 Supabase 或受委托的服务商。下面讲清楚每一类数据是什么、为什么处理、保存多久，以及你怎样删除。

一、我们处理哪些信息

1. 本机刷题、错题和学习统计

你在 App 内做判断题、单选题、多选题、填空题时，App 会在本机记录题目编号、作答结果、作答时间、错题次数和学习统计，存放在 App 私有数据库中。未登录时这些数据不会离开手机；登录后，App 会把答题记录、错题和错题次数同步到 Supabase，以便换设备继续复习。

你可以在“设置与帮助 → 清除本机刷题数据”删除本机记录；注销账号会同时删除 Supabase 中属于该账号的数据。

2. 邮箱账号与登录状态

App 使用 Supabase Auth 提供邮箱登录和自助注册。登录时 Supabase 会处理你的邮箱、加密后的密码凭据、用户 ID、邮箱确认状态和登录令牌；App 会在本机保存访问令牌与刷新令牌，用于返回 App 后保持登录，避免重复输入密码。

内部账号和外部体验账号的权限不同：内部账号可查看完整 7 章资料和 55 道原生题；外部自助注册账号和未登录用户只能查看第一章资料、体验题等部分内容。内部账号由站长在后台标记，普通注册不会自动获得完整权限。

3. 网站学习进度、错题和做题记录

当你登录学习站时，网站会把学习进度、错题状态和部分答题记录保存到 Supabase 的 study_progress、wrong_questions、attempts 表，用于跨设备同步。网站仍会使用浏览器本地存储保存当前页面的学习状态；清除浏览器数据会删除本机副本。

4. 意见反馈与截图

你可以在 App 的“我的 → 意见反馈”提交 Bug、功能建议、题库纠错或其他反馈，并可选择上传截图。反馈内容会写入 Supabase 的 feedback 表；截图会存入私有的 feedback-images 存储桶，路径以你的用户 ID 开头，仅用于排查问题和改进题库。未登录时只允许提交纯文字反馈；截图上传需要登录账号。

反馈内容最多 2000 字，图片单张不超过 5MB。请不要在反馈中填写身份证号、银行卡号、密码等敏感信息。

5. AI 答疑与错题解析

当你主动点击右下角“AI 答疑”或错题旁的“AI解析”时，你输入的计算机问题、错题题干与选项、你的答案、正确答案、站内 7 章中与问题相关的片段，以及最近几轮对话，会通过 Supabase Edge Function 中转，发送给受委托的大模型服务商；当站内片段不足时，检索关键词和问题还会发送给联网搜索服务商。浏览器和 App 不直接保存模型或搜索服务商的密钥。

AI 问答会写入 Supabase 的 ai_conversations、ai_messages 表，用于历史记录和跨设备同步；每日调用次数写入 ai_usage_daily 表。你可以在 AI 弹窗的“历史 → 清空全部对话”删除问答记录；注销账号会级联删除这些表及用量记录。请不要在问题中填写身份证号、银行卡号、密码、住址等与备考无关的敏感信息。

AI 回答由模型生成，联网检索内容可能存在误差，仅供备考参考；重要知识点请以教材、考试大纲和官方通知为准。若你不同意将上述内容发送给模型或搜索服务商，请不要使用 AI 答疑和 AI解析；这不影响刷题、错题本、背诵册等本机或云同步功能。

6. 学习提醒与导出

每日学习提醒的开关和时间只保存在本机，通过 Android 通知触发；不开启不影响刷题。导出刷题记录使用 Android 系统文件选择器，由你决定保存位置，App 不会在后台读取你的文件。

二、设备权限

  • 网络与网络状态：用于 Supabase 登录/同步、打开学习站和提交反馈。
  • 通知：仅用于你主动开启的每日学习提醒。
  • 开机广播：用于重启手机后恢复你已开启的学习提醒。
  • 文件选择：仅在你主动选择反馈截图或导出 JSON 时，通过 Android 系统选择器读取你指定的文件。

App 不申请读取通讯录、短信、位置、相机、麦克风或电话状态的权限；不使用广告 SDK，不进行个性化广告推送，不向第三方出售个人信息。

三、第三方服务

  • Supabase：提供邮箱账号、数据库、学习进度/错题/答题记录、反馈、AI 会话与用量记录，以及私有截图存储。项目区域为东京（Northeast Asia / ap-northeast-1）。
    Supabase 隐私政策
  • AI 模型服务商与联网搜索服务商：仅在主动使用 AI 答疑或 AI解析时，经 Supabase Edge Function 中转处理问题、相关站内片段和最近对话；服务商按各自隐私政策处理，具体名称与处理区域以部署时的服务商配置为准。
    浏览器和 App 不直接持有这些服务的密钥。
  • GitHub Pages：托管学习站静态页面，访问时可能记录常规访问日志（IP、时间、请求路径）。
    GitHub 隐私声明

原生刷题、错题本、学习提醒和导出文件不经过 GitHub Pages；只有你登录或使用云同步时，相关数据才会写入 Supabase。AI 答疑与 AI解析只在主动使用时联网，问题与相关片段会经 Supabase Edge Function 中转给模型和搜索服务商。第三方服务可能按照其自身政策在境外处理数据；如你不同意，请不要登录账号、使用云同步或 AI 功能，仍可使用本机刷题和第一章体验内容。

四、保存期限与安全

本机数据保存到你在 App 内清除、注销账号或卸载 App 为止。Supabase 中的账号、学习进度、错题、答题记录和反馈，保存到账号被注销或你联系开发者删除为止；注销账号后，业务表通过外键级联删除，私有截图随账号数据清理。我们使用 HTTPS 传输，并禁止 App 使用明文 HTTP；数据库启用行级安全策略，每个登录用户只能访问自己的数据。任何网络传输都无法承诺绝对安全。

五、你的权利

  • 查询/复制：在 App 内查看刷题统计，使用“导出本机刷题记录”；在“我的”查看当前账号类型和邮箱。
  • 删除本机数据：设置 → 清除本机刷题数据。
  • 注销账号：App “我的 → 注销账号”，输入“注销”确认后，Supabase 账号及关联数据会立即删除；网站账号面板也提供注销入口。注销不可恢复。
  • 撤回同意：退出登录、关闭学习提醒，或不再使用联网功能；撤回不影响此前基于同意进行的处理。

六、未成年人

本应用面向备考专升本的学习者，不专门面向 14 周岁以下儿童。如果你未满 14 周岁，请在监护人陪同下阅读本政策并使用；监护人不同意时，请不要使用联网的账号、云同步和反馈功能。我们不会主动收集未成年人的身份信息。
