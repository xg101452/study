①

数据管理的三个阶段

★★考"哪个阶段有什么特点"
阶段时间特点
人工管理20 世纪 50 年代没有专门的管理软件；数据不长期保存；数据面向程序、不能共享；程序员自己管数据
文件系统20 世纪 60 年代数据以文件形式长期保存，由文件系统管理；但数据冗余大、共享性差、独立性差（数据与程序仍有依赖）
数据库系统20 世纪 60 年代末至今数据结构化；共享性高、冗余低；独立性高；由 DBMS 统一管理和控制
一条趋势线：无管理 → 文件管理 → 数据库管理；冗余从大变小、共享从无到有、独立性从差到好。
判断题常这么出："文件系统阶段数据已完全独立于程序"——错（独立性差）。
②

五个概念：数据、记录、数据库、DBMS、DBS

★★★2025 单选第 5 题就在这
概念定义
数据描述事物的符号记录，包括数字、文字、图形、图像、声音等
记录二维表中的一行，描述一个具体对象（如一名学生）
字段二维表中的一列，即一个属性（如姓名、年龄）
数据库（DB）长期存储在计算机内、有组织、可共享的数据集合
数据库管理系统（DBMS）位于用户与操作系统之间的系统软件，负责定义、操纵、管理、维护数据库
数据库系统（DBS）数据库 + DBMS + 应用程序 + 人员（含 DBA）
数据库应用系统面向具体业务、由数据库支持的软件系统（如教务系统、图书管理系统）
真题2025 · 单选 5（2 分）　下列软件中，不属于数据库管理系统的是（　）
A. MySQL　B. SQL Server　C. Chrome　D. Access
答案：C。Chrome 是浏览器，与数据库无关。
另外三个都是 DBMS：MySQL（开源）、SQL Server（微软）、Access（Office 自带的小型桌面数据库）。Oracle 也是，一起记住。
DBMS 的四大功能（简答可写）：①数据定义（建表、建库）；②数据操纵（查询、插入、修改、删除）；③数据库运行管理（并发控制、安全性、完整性）；④数据库的建立与维护（备份、恢复、重组）。
三个词别混：DB 是"仓库"（数据本身）；DBMS 是"管理员"（软件）；DBS 是"整套系统"（仓库＋管理员＋应用＋人）。题目问"数据库系统由什么组成"，答的不是"数据+程序"，而是四项。
③

数据模型：三要素与三种模型

★★★2025 判断第 29 题
真题2025 · 判断 29　数据模型通常由数据结构、数据操作和完整性约束三部分组成。
→ 正确。三要素：数据结构（怎么组织）、数据操作（能做什么）、完整性约束（有什么规则）。这句可以直接背。
模型结构形态特点
层次模型树形有且仅有一个根节点，一对多；结构简单但不宜表示复杂联系
网状模型图（网状）可以有多个根节点，多对多；联系灵活但结构复杂
关系模型二维表用表格表示实体与联系，概念单一、易理解、有严格数学基础；当前主流
真题2025 · 单选 6（2 分）　用二维表结构表示实体及实体间联系的数据模型称为（　）
A. 层次模型　B. 网状模型　C. 关系模型　D. 面向对象模型
答案：C。看到"二维表"三个字，直接选关系模型。反过来，看到"树形"选层次，"网状/图"选网状。
E-R 图（概念模型，用来设计数据库）：三要素是实体（矩形）、属性（椭圆）、联系（菱形）。联系有三种：一对一（1:1）、一对多（1:n）、多对多（m:n）。
例：学生—选修—课程 是多对多；班级—学生 是一对多；人—身份证 是一对一。
④

关系模型的基本术语

★★★2024 判断：主键可由多个字段组成
术语含义（对照表格）
关系一张二维表
元组表中的一行（一条记录）
属性表中的一列（一个字段）
主键（主关键字）唯一标识一个元组的属性或属性组；不能重复、不能为空
外键（外关键字）本表中的某属性，是另一张表的主键，用于建立两表联系
候选键能唯一标识元组的属性组，选其中一个作主键
真题2024 · 判断　关系数据库中的主键只能由一个字段组成。
→ 错误。主键可以由多个字段共同组成，称为"复合主键"（如"学号+课程号"共同作为选课表的主键）。只要这组字段合起来能唯一标识一行，就可以作主键。
一句话对照记：关系＝表、元组＝行、属性＝列、主键＝身份证号、外键＝指向别人的身份证号。
⑤

选择、投影、连接：管行还是管列

★★★最容易混的一组
运算作用对象含义
选择（Selection）行（元组）按条件筛选出满足条件的行，相当于"挑记录"
投影（Projection）列（属性）按指定列取出数据，去掉不需要的列，相当于"挑字段"
连接（Join）两张表按公共属性（连接条件）把两张表横向拼成一张
口诀：选择管行、投影管列、连接管两表。
记不住就用英文：Select 挑行（WHERE 条件）、Project 挑列（列清单）、Join 拼表。
举例学生表（学号、姓名、性别、班级、成绩）
· "找出成绩大于 90 的学生" → 选择（筛行）
· "只列出学号和姓名两列" → 投影（去列）
· "把学生表和班级表按班级号拼起来" → 连接（拼表）
⑥

SQL 一句话与四种常用 DBMS

★★2025 单选 7、2026 SELECT 题
SELECT 列名（投影：要哪些列） FROM 表名 WHERE 条件（选择：要哪些行） ORDER BY 排序列 ASC/DESC 例：查询成绩大于 90 的学生姓名 SELECT 姓名 FROM 学生 WHERE 成绩 > 90;
语句类别作用
CREATEDDL（数据定义）建立数据库/表/索引
DROP / ALTERDDL删除 / 修改表结构
SELECTDQL（查询）检索数据
INSERT / UPDATE / DELETEDML（数据操纵）插入 / 修改 / 删除记录
真题2025 · 单选 7（2 分）　SQL 语言中，用于建立数据库对象的语句是（　）
答案：CREATE。看到"建立/创建"，就是 CREATE；它属于 DDL（数据定义语言）。
同类区分：SELECT 是查询、INSERT 是插入、DROP 是删除。"建"字开头一律 CREATE。
2026 还考了一道 SELECT 语句题（给出表与语句，问查询结果/含义）。做法：先看 SELECT 后面列了什么（列），再看 WHERE 限定了什么（行），然后对着表找答案。不要凭感觉，一定按"列→行"顺序读。
DBMS定位
Access微软 Office 组件，小型桌面数据库，适合个人与小部门
SQL Server微软，中大型企业级，与 Windows 集成好
MySQL开源免费，Web 应用最常用（LAMP 组合）
Oracle大型商业数据库，金融、电信等高端场景

#内容
1数据管理三阶段：人工管理 → 文件系统 → 数据库系统，冗余递减、共享递增
2数据库（DB）＝有组织、可共享的数据集合；DBMS＝管理数据库的系统软件

三、填空与简答（4 题）

11. 数据库系统由数据库、______、应用程序和人员组成。
数据库管理系统（DBMS）。
12. 关系模型中，表中的一行称为 ______，一列称为 ______。
元组、属性。
13. 简述数据库系统的特点。
参考答案：①数据结构化，数据之间有联系；②数据共享性高、冗余度低，可被多用户多应用共享；③数据独立性高，数据的逻辑结构与物理存储改变时应用程序不必修改；④由 DBMS 统一管理和控制，提供安全性、完整性、并发控制与恢复功能。
14. 简述选择、投影、连接三种关系运算的区别。
参考答案：①选择：按给定条件筛选满足条件的行（元组），是"挑记录"；②投影：从表中选取指定的列（属性），去掉不需要的列，是"挑字段"；③连接：把两张表按公共属性（连接条件）横向拼接成一张新表，是"拼表"。
