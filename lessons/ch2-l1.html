①

计算机系统的组成：两大部分、四个层次

★★最容易出一句话判断
计算机系统 ├── 硬件系统（看得见摸得着） │ ├── 主机：CPU（运算器 + 控制器）、内存、主板、总线、电源 │ └── 外设：外存（硬盘/U盘/光盘）、输入设备、输出设备 └── 软件系统（程序 + 数据 + 文档） ├── 系统软件：操作系统、语言处理程序、数据库管理系统、各类服务程序 └── 应用软件：办公软件、浏览器、微信、各类专业软件
层次内容判断要点
硬件构成计算机的物理实体，是物质基础没有软件，硬件是"裸机"，不能工作
软件程序 + 数据 + 文档三者的集合（不是"程序"一项）"软件就是程序" → 错
系统软件管理硬件、支持应用软件运行、由厂商提供操作系统、编译程序、数据库管理系统
应用软件为解决某一具体问题而开发Word、Excel、浏览器、微信
两个高频错法：
① "软件就是程序"——错，软件 = 程序 + 数据 + 文档；
② "系统软件是用户为解决某个问题开发的"——错，系统软件由厂商提供，应用软件才是为用户的具体需求开发。
人话解释 · 为什么硬件和软件要分开算 硬件是"身体"，软件是"会做的事"。同一台电脑，装 Windows 能做办公，装 Linux 能做服务器——身体一样，能力不同。所以考纲说"计算机系统 = 硬件 + 软件"，强调的就是"缺一个都不算完整系统"。
②

冯·诺依曼体系结构：三要点、五部件

★★★全章最核心的一张图，简答/填空/判断都从这里出
输入设备 ↓ ┌───────────────────┐ │ 存储器（内存） │ ←→ 外存 └───────────────────┘ ↑ ↓ ┌───────────────────┐ │ 运算器 + 控制器 │ = CPU └───────────────────┘ ↓ 输出设备
三要点含义为什么重要
① 二进制表示程序和数据都用二进制形式表示统一了"指令"和"数据"的形式，才能一起存
② 存储程序控制把程序（指令序列）事先存入存储器，由计算机自动按顺序取出并执行这是整个体系的核心思想，也是"自动计算"的前提
③ 五大部件运算器、控制器、存储器、输入设备、输出设备规定了硬件的功能分工
部件功能归属与别名
运算器完成算术运算与逻辑运算与控制器合称 CPU；又叫 ALU（算术逻辑单元）所在部分
控制器指挥、协调各部件，取指令、分析指令、发控制信号是"司令部"，与运算器合称 CPU
存储器存放程序和数据分内存（主存，CPU 可直接访问）与外存（辅存，需调入内存）
输入设备把外部信息送入计算机键盘、鼠标、扫描仪、触摸屏（兼输入输出）
输出设备把结果送出给人或外部显示器、打印机、绘图仪、音箱
一句话记忆：冯·诺依曼 = 二进制 + 存储程序 + 五大部件；其中"存储程序控制"是最本质的特征。
人物对照：冯·诺依曼＝现代计算机之父（1945 年提出 EDVAC 方案）；图灵＝计算机科学之父、人工智能之父（1936 年图灵机模型）。
怎么答"冯·诺依曼体系结构的内容"这道简答（5 分）：
①计算机由运算器、控制器、存储器、输入设备、输出设备五大部件组成；②程序和数据以二进制形式表示；③程序和数据存放在存储器中，计算机按存储程序控制方式自动执行；④以运算器为中心改为以存储器为中心（现代改进）。四条按顺序写，不必展开。
③

指令与程序的执行过程

★★常考"顺序"和"指令由什么组成"
概念说明
指令计算机执行一个基本操作的命令。由操作码（做什么）+ 地址码（对谁做、数据在哪）两部分组成
程序为完成某一任务而编写的有序指令序列
指令系统一台计算机全部指令的集合，由硬件决定，是衡量计算机性能的重要标志
指令执行的基本过程（一个指令周期） ① 取指令（Fetch） —— 按程序计数器 PC 的地址，从内存取出指令送到指令寄存器 ② 分析指令（Decode） —— 控制器对操作码译码，判断要做什么 ③ 执行指令（Execute）—— 由运算器或相应部件完成操作 ④ 存结果（Store） —— 把结果写回寄存器或内存，并修改 PC 指向下一条 四条循环往复 → 这就是"存储程序控制"在工作
易错：① 指令的操作码决定"做什么"，地址码决定"数据在哪"，两者不要对调；② 程序是"有序指令序列"，顺序不可乱，"一堆指令"不等于程序；③ 指令系统由硬件决定，不同 CPU 指令系统不同（所以程序不能随便跨平台直接跑）。
④

总线：三种类型、三个层次

★★★2025 填空第 46 题就是这里，3 分
先理解"总线是什么" 一堆部件要互相传数据，如果两两之间都拉一根线，线会多到不可收拾。所以约定一条公共通道，所有部件都挂上去、轮流用——这条公共通道就是总线。它的本质是"共享的传输线路"，不是某个零件。
类型传什么关键结论
数据总线（DB）传送数据根数（宽度）＝CPU 一次能同时传输的二进制位数，决定字长
地址总线（AB）传送地址根数决定可寻址的内存空间（n 根 → 2n 个单元）
控制总线（CB）传送控制信号、时序信号、状态信号方向不固定，有单向也有双向
这三条合起来就是"系统总线"。2025 年填空 46 问"系统总线分为______、地址总线和控制总线"，答案就是 数据总线——这 3 分几乎等于白送，前提是你知道"系统总线 = 三总线"。
层次位置说明
内部总线CPU 芯片内部连接运算器、寄存器等，速度最快
系统总线主机内部连接 CPU、内存、I/O 接口，就是上面那三条
外部总线主机与外部设备之间如 USB、串口、并口
真题2024 · 判断 3　总线带宽是指总线在同一时刻能同时传输的二进制位数。
→ 错。"同时传输的二进制位数"是总线宽度；带宽 = 宽度 × 总线频率（单位 B/s），是"单位时间能传多少"。两个概念一宽一快，别混。
⑤

主板与 BIOS

★只需要知道"是什么、装在哪"
对象是什么考点
系统主板
（主机板/母板）		主机箱内最大的一块电路板，是各部件的连接枢纽，上面有 CPU 插槽、内存插槽、芯片组、BIOS 芯片、I/O 接口和总线"主板是连接各部件的枢纽/平台，不是运算部件"
BIOS基本输入输出系统，一段固化在 ROM 中的程序，负责加电自检、初始化硬件、引导操作系统它不是操作系统的一部分，在操作系统之前运行
真题2025 · 判断 23　BIOS 是操作系统的一部分。
→ 错。BIOS 固化在主板的 ROM 里，负责上电自检和引导，早于操作系统运行；操作系统装在硬盘上，是另一个层次的东西。
顺手记住这条链：加电 → BIOS 自检 → 引导程序 → 装入操作系统 → 操作系统接管硬件。所以 BIOS 坏了，机器连"开机"这一步都过不去，更谈不上进系统。

#内容
1计算机系统 = 硬件系统 + 软件系统；软件 = 程序 + 数据 + 文档
2软件分系统软件（OS、语言处理程序、DBMS）与应用软件（办公、浏览器、微信）

7指令执行四步：取指令 → 分析指令 → 执行指令 → 存结果
8系统总线 = 数据总线 + 地址总线 + 控制总线
9数据总线宽度＝一次传输的位数；地址总线宽度决定寻址空间；带宽 = 宽度 × 频率

一、判断题（4 题）

1. 计算机软件就是程序。
错误。软件 = 程序 + 数据 + 文档，缺一不可。
2. 冯·诺依曼体系结构的核心思想是存储程序控制。
正确。把程序存入存储器，由机器自动按序执行，这是"自动计算"的根本。
3. 总线带宽是指总线在同一时刻能同时传输的二进制位数。
错误。那是总线宽度；带宽 = 宽度 × 频率，单位是字节/秒。
4. BIOS 是操作系统的一部分，装在硬盘上。
错误。BIOS 固化在主板的 ROM 中，负责加电自检与引导，运行在操作系统之前。

二、单项选择题（4 题）

5. 下列不属于系统软件的是（　）
A. Windows　B. 编译程序　C. 数据库管理系统　D. Excel
D。Excel 是办公应用软件。
6. 冯·诺依曼计算机的五大部件中，负责指挥协调各部件工作的是（　）
A. 运算器　B. 控制器　C. 存储器　D. 输入设备
B。控制器是"司令部"，负责取指令、分析指令、发出控制信号。
7. 一条指令通常由（　）两部分组成
A. 操作码和地址码　B. 数据码和控制码　C. 源地址和目的地址　D. 指令码和状态码
A。操作码＝做什么，地址码＝数据在哪。
8. 系统总线不包括（　）
A. 数据总线　B. 地址总线　C. 控制总线　D. 电源总线
D。系统总线只有数据、地址、控制三类。
