①

三种基本结构

★★★共同点：一个入口、一个出口
结构执行方式典型语句
顺序结构按书写顺序从上到下逐条执行，每条执行一次赋值、输入、输出
选择结构根据条件是否成立决定走哪条分支，必有一条被执行if、if-else、switch / 多分支
循环结构条件成立时反复执行循环体，直到条件不成立while、do-while、for
三种结构的共同特征（判断题爱考）：①只有一个入口和一个出口；②结构内的每一部分都有机会被执行到（不存在永远走不到的死代码）；③结构内不存在死循环。这三条就是"结构化程序设计"的基本要求。
结构化程序设计的三种基本结构：顺序、选择、循环。（有的教材加"模块化"，但基本结构只有这三种。）
②

当型与直到型：循环体执行几次

★★★2025 判断第 34 题
当型（while）：先判断，后执行 ┌→ 判断条件 ─ 假 → 退出 │ │真 │ ▼ └── 执行循环体 → 条件一开始就不成立时，循环体执行 【0 次】 直到型（do-while）：先执行，后判断 ┌→ 执行循环体 │ ▼ └── 判断条件 ─ 真 → 回去再执行 └ 假 → 退出 → 无论条件如何，循环体至少执行 【1 次】
对比项当型（while）直到型（do-while）
判断位置循环体之前判断循环体之后判断
最少执行次数0 次1 次
条件为真时继续执行继续执行（真→回去）
适用可能一次都不做的情况至少要执行一次的情况
真题2025 · 判断 34　在循环结构中，循环体中的语句至少会被执行一次。
→ 错误。当型（while）循环先判断条件，条件一开始就为假时，循环体一次都不执行。"至少执行一次"只对直到型成立。
看到"至少执行一次""一定执行"这类绝对化表述，先想 while。
另一个常见坑：for 循环 for(i=1;i<=n;i++) 的循环体执行 n 次；而 for(i=0;i<n;i++) 也是 n 次。数次数看的是初值与终值的关系，不是看写法。

流程图的基本符号

★★认框的形状就能答
符号（形状）名称用途
圆角矩形 / 椭圆起止框表示算法的开始与结束
矩形处理框赋值、计算等处理操作
菱形判断框条件判断，有"是/否"两条出口
平行四边形输入 / 输出框输入数据、输出结果
圆形 / 小圆连接点连接流程图的断开部分
带箭头直线流程线表示执行方向
注释符（虚线框）注释对流程的说明
四句话记形状：圆角起止、矩形处理、菱形判断、平行四边形输入输出。看到菱形，就找"是/否"分支；看到平行四边形，就知道在读数或印数。
④

累加与累乘：初值最容易错

★★看流程图算结果的主角
累加 1+2+3+…+n s ← 0 ← 初值必须是 0 i ← 1 当 i ≤ n 时： s ← s + i i ← i + 1 输出 s 结果 = n(n+1)/2 n=100 → 5050 累乘 1×2×3×…×n （即 n!） p ← 1 ← 初值必须是 1（写 0 就永远是 0） i ← 1 当 i ≤ n 时： p ← p × i i ← i + 1 输出 p 结果 = n! n=5 → 120
初值三句话：累加初值写 0，累乘初值写 1，计数器初值看起点。
如果把累乘的 p 初始化成 0，无论乘多少次结果都是 0——这是流程图题最常见的"埋雷"方式，做题时第一眼就去看初值。
变体：累加偶数和（1～100 的偶数之和＝2550）。做法是循环里加一个判断 i 除以 2 余数为 0 才累加，这就是"循环＋选择"的组合，也是综合题最爱考的形式。
⑤

顺序查找与二分查找

★★★二分的前提是有序
对比项顺序查找二分查找（折半查找）
前提无要求，任何序列都行必须有序（递增或递减均可）——2024 判断考过
做法从头到尾逐个比较每次与中间元素比较，排除一半
最多比较次数n 次⌈log₂n⌉ 次（n=1000 时约 10 次）
平均比较次数(n+1)/2约 log₂n
时间复杂度O(n)O(log₂n)
适用数据少、无序、频繁插入删除数据多、有序、很少变动
真题2024 · 判断　二分查找法要求线性表必须按关键字递减有序排列。
→ 错误。原题表述为"必须递增有序"，也错——递增或递减有序都可以，关键是有序。所以"必须是递增""必须是递减"这类限定都不对。
记结论：二分查找的前提是"有序"，不是"递增有序"。
算次数的小技巧：二分查找 n 个元素，最多比较 ⌈log₂n⌉ 次。2⁹＝512、2¹⁰＝1024，所以 1000 个元素最多 10 次，100 个元素最多 7 次（2⁶＝64 不够，2⁷＝128 够）。
⑥

冒泡排序：趟数、次数、提前结束

★★★2025 判断第 35 题
做法（人话版） 从头开始，相邻两个数比较，大的往后换；走完一趟，最大的数就"冒"到了最后一位。下一趟只在前 n−1 个里继续，直到全部有序。
问题答案
n 个数最多需要几趟n−1 趟（每趟定住一个数，最后一个自然就位）
第 i 趟需要比较几次n−i 次
总共比较多少次（最坏）n(n−1)/2
时间复杂度O(n²)
什么时候可以提前结束某一趟没有发生任何交换，说明已经有序，可立即结束
真题2025 · 判断 35　在冒泡排序过程中，如果某一趟比较没有发生任何数据交换，则可以提前结束排序。
→ 正确。没有交换＝相邻元素都已满足顺序＝整个序列已有序，再比较下去也是白做。这也是冒泡排序"最好情况 O(n)"的原因（原序列已有序时只需一趟）。
三个数字背下来：n−1 趟、第 i 趟比 n−i 次、总共 n(n−1)/2 次。
例：5 个数排序→ 最多 4 趟，比较 4+3+2+1＝10 次。
冒泡的方向别搞错：升序排列时，每趟把最大的送到末尾（大的往后换）；降序则相反。题目问"第一趟结束后哪个数一定在最终位置"——答"最大（或最小）的那个数"。
⑦

看流程图算结果：三步法

★★★综合应用题的原型
第一步：找初值 —— 循环开始前，每个变量等于几？ 第二步：找条件 —— 循环在什么条件下继续？什么时候停？ 第三步：找规律 —— 循环体每次对变量做了什么？（加？乘？交换？） 三步走完，把 n 取小一点（如 n=3、4）手工跑一遍，答案就出来了。
例题看下面流程，写出输出结果（n 输入为 5）
输入 n s ← 0 ; i ← 1 当 i ≤ n 时： s ← s + i × i i ← i + 1 输出 s
解析：这是平方累加。s ＝ 1²+2²+3²+4²+5² ＝ 1+4+9+16+25 ＝ 55。
识别关键：初值 0 → 是累加；循环体是 i×i 而不是 i → 加的是平方，不是自然数。
四类"看图说功能"的标准答案：
① s←s+i → 累加求和；② p←p*i → 累乘求阶乘；③ 比较并交换 + 双层循环 → 排序（冒泡）；④ 有序序列中取中间比较、缩小区间 → 二分查找。
答题格式提醒：综合应用题按步骤给分。写"功能"时不要只写"求和"，要写"求 1 到 n 的平方和"；写"结果"时把算式和数值都写上，例如"1²+2²+…+5²＝55"。

三、填空与简答（4 题）

11. 三种基本结构是顺序结构、选择结构和 ______。
循环结构。
12. 执行"s←0；i←1；当 i≤100 时 s←s+i，i←i+1"，输出 s ＝ ______。
5050（1+2+…+100）。
13. 简述当型循环与直到型循环的区别。
参考答案：①当型（while）在循环体之前判断条件，条件为真才执行循环体，条件一开始不成立时循环体一次都不执行（最少 0 次）；②直到型（do-while）先执行循环体、之后再判断条件，条件为真则继续，循环体至少执行一次。
14. 简述冒泡排序的基本思想，并说明 n 个数最多需要多少趟。
参考答案：①基本思想：从第一个元素开始，相邻两两比较，若顺序不符合要求则交换，一趟下来最大的（升序时）元素被送到末尾；下一趟在剩余元素中重复，直到全部有序。②趟数：n 个数最多需要 n−1 趟；第 i 趟比较 n−i 次，最坏共比较 n(n−1)/2 次，时间复杂度 O(n²)。③若某一趟没有发生交换，说明已有序，可提前结束。
