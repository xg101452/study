工作簿、工作表、单元格是什么关系？地址怎么写？

工作簿＝一本账本，工作表＝账本里的一页，单元格＝页上的一个格子。格子地址＝列字母+行号（B3）。
关键在“引用”：相对地址 B3 复制会跟着变，绝对地址 $B$3 复制不变，混合 $B3/B$3 锁一半。本课就把这三种地址和填充柄练熟。

三个层级：工作簿 → 工作表 → 单元格

★谁包含谁，一定要分清
工作簿（.xlsx 文件） ← 一个文件 ├── 工作表1（Sheet1） ← 一张"页"，下方标签 │ ├── 单元格 A1 │ ├── 单元格 B2 │ └── 区域 A1:C3 ├── 工作表2 └── 工作表3
概念说明
工作簿一个 Excel 文件，扩展名 .xlsx（旧版 .xls）
工作表工作簿里的一张"表"，用底部标签区分；可增、删、重命名（双击标签）、移动、复制、隐藏
单元格行列交叉的最小单位，是数据的最小载体
单元格地址列标 + 行号：A1、B3、XFD1048576
区域用冒号表示左上到右下：A1:C3（3 行 3 列，共 9 格）
多个不连续区域用逗号分隔：A1:A3,C1:C3
两句必记：①"工作表就是工作簿"——错，工作簿是文件，工作表是文件里的一页；②"删除工作表就是把内容清空"——错，删除会把整张表连同格式一起去掉，且不可撤销（清空内容才只是 Clear）。
区域计数速算：A1:C3 = 3 列 × 3 行 = 9 个单元格；B2:D5 = 3 列 × 4 行 = 12 个单元格。先数列、再数行、相乘，别一个个点。
②

数据录入与编辑的五个"技巧点"

★★★这些细节年年出现在选择/填空里
要输入的内容正确做法直接输入会怎样
编号 001、002（文本型数字）先输英文单引号 '，再输 001变成数字 1，前面的 0 消失
分数 1/2先输 0 和一个空格，再输 1/2被识别成日期（1 月 2 日）
以 = 开头的文本前置单引号 '=被当成公式并报错
单元格内换行Alt + Enter按 Enter 会跳到下一格
当前日期 / 时间Ctrl + ; 日期，Ctrl + Shift + ; 时间手工输入也可以，但易错格式
一列有规律的序列拖填充柄（单元格右下角小黑点）——
填充柄的两种行为（考"按住 Ctrl 拖会怎样"） 直接拖填充柄 → 复制相同内容（文本、数字都一样） 按住 Ctrl 拖 → 递增（1,2,3…） 输入前两个再选两个一起拖 → 按"等差"规律填充（1,3,5…） 日期、星期、月份、甲乙丙 → 内置序列，直接拖就递增
一眼判断数据类型：文本靠左、数字靠右、逻辑值居中。看到某个"数字"靠左对齐，多半是被当成了文本（这也是输入身份证号、手机号要加 ' 的原因）。
选择性粘贴（常考小题）：复制后"选择性粘贴"可以只粘数值（去掉公式）、只粘格式、只粘列宽、转置（行列互换）。题目问"只保留计算结果不要公式"，答案＝选择性粘贴→数值。
③

工作表格式化

★★数字格式与条件格式是重点
格式类别说明
常规默认格式，输入什么显示什么
数值可设小数位数、是否使用千位分隔符、负数显示方式
货币 / 会计专用带货币符号（￥、$），会计专用会对齐货币符号
百分比0.25 显示为 25%（数值本身不变，只改显示）
日期 / 时间多种显示样式，如 2026-11-19、2026年11月19日
科学记数如 1.23E+05
文本按文本处理，长数字不再变科学记数
自定义自己写格式代码（了解即可）
关键理解：改格式≠改数值。把 0.25 设成百分比，单元格里存的还是 0.25，只是显示为 25%；把数字设成"两位小数"，实际值也不变，参与计算仍用原值。题目说"设置格式后数值变小了"——一律判错。
其他格式化要点
字体 / 对齐 / 边框 / 底纹与 Word 类似；单元格内可设水平+垂直对齐
合并居中把多个单元格并成一个（做标题常用）。合并后只保留左上角的值，且会影响排序与筛选
行高 / 列宽可拖动边界，也可"自动调整"；双击列标边界＝按内容自动调宽
条件格式满足条件才变样式：数据条、色阶、图标集、突出显示规则（如大于 90 分标红）
格式刷把一处格式复制到另一处；双击格式刷可连续刷
套用表格格式 / 单元格样式一键套用成套配色与边框
合并居中的副作用要记：合并后的区域只保留左上角单元格的数据，其余被清空；且合并区域无法正常参与排序、筛选、透视，也无法单独复制其中一格。"为了排序方便先合并居中"是错的。

三种单元格地址：相对、绝对、混合

★★★四川卷 Excel 部分的"必得分"
引用形式名称复制到别的单元格时
A1相对引用行、列都跟着变（随位移偏移）
$A$1绝对引用行、列都不变
A$1混合引用（锁行）列变、行不变
$A1混合引用（锁列）列不变、行变
口诀：$ 在字母前 → 锁列；$ 在数字前 → 锁行；两个 $ → 行列都锁。
复制时"锁住的不动，没锁的跟着走"——往下复制只改行号，往右复制只改列标。
切换方式：选中地址后反复按 F4 A1 → $A$1 → A$1 → $A1 → A1 （四种状态循环） （注意顺序：先全锁，再锁行，再锁列）
真题2025 · 单选 12（2 分）　公式 =MAX(A1!B1:B9) 中，A1 表示（　）
A. 单元格地址　B. 工作表名　C. 工作簿名　D. 函数名
答案：B。
跨工作表引用的写法：工作表名!单元格区域，中间的感叹号是"跨表"的标志。若表名含空格或特殊字符，要加单引号，如 '销售 表'!B1。
本题里 A1 不是单元格，而是名为 A1 的工作表——这是出题人故意的陷阱，看到 ! 就要条件反射"前面是表名"。
跨工作簿引用还要加文件名：[成绩.xlsx]Sheet1!A1。这个只需认得，不必深究。

引用题实战：2025 那道 2 分题

"复制公式"类题的标准解法
真题2025 · 单选 11（2 分）　C1 单元格中的公式为 =A$1*SUM($B1:$B3)，将该公式复制到 D3 单元格后，公式变为（　）
A. =B$1*SUM($B3:$B5)　B. =B$3*SUM($C1:$C3)　C. =A$3*SUM($B3:$B5)　D. =B$3*SUM($B1:$B3)
答案：A。
三步解法（每道引用题都这么做） 第 1 步：算位移。C1 → D3：列从 C 到 D，右移 1 列；行从 1 到 3，下移 2 行。
第 2 步：逐个地址判断"锁没锁"。
　A$1：字母 A 没锁 → 列 +1 变 B；数字 $1 锁了 → 行不变。结果 B$1。
　$B1：字母 $B 锁了 → 列不变；数字 1 没锁 → 行 +2 变 3。结果 $B3。
　$B3（区域右下角）：同理 → $B5。
第 3 步：拼回去。=B$1*SUM($B3:$B5)，选 A。
三个"看错就错"的地方：①区域 $B1:$B3 的两个端点都要各自换算，不能只改一个；②行号加的是 2 不是 3（1→3 是 +2）；③函数名 SUM 不参与变化，别把 SUM 也改了。
一句话总结整节：先算"右移几列、下移几行"，再看每个地址的 $ 锁在哪，锁住的不动、没锁的加位移，最后原样拼回公式。

一、判断题（5 题）

错误。可包含多张，可增删。

错误。显示为 1；要保留前导 0 须前置英文单引号。

错误。只改变显示方式，实际值不变。

错误。只保留左上角单元格的数据。
