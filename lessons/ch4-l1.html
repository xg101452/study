①

网络是什么，用来干什么

★★★"最主要功能"是必考点
定义（一句话） 计算机网络是把地理位置分散、具有独立功能的多台计算机，通过通信线路与网络设备连接起来，在网络协议管理下实现资源共享与数据通信的系统。
功能说明地位
资源共享共享硬件（打印机、存储）、软件、数据（数据库、文件）最主要、最本质的功能
数据通信电子邮件、即时消息、文件传输最基本的功能
分布式处理把大任务拆给多台机器协同完成提高效率
提高可靠性一台故障可由另一台替代容错
题干出现"计算机网络最主要的功能"→ 答资源共享，不要答"数据通信"。数据通信是"最基本"的，资源共享是"最主要/最本质"的——"最基本"和"最主要"在四川卷里是两个不同的答案。
网络的三个组成要素 ① 多台独立的计算机（各自能独立工作） ② 连接它们的通信线路与设备（介质 + 网卡/交换机/路由器） ③ 共同遵守的网络协议（没有协议就只是"连着的机器"，不是网络）
为什么强调"独立功能"？因为"一台主机 + 若干终端"（如早期终端连主机）不算真正的网络——终端本身不能独立处理任务。判断题常在这里设陷阱。
②

发展与分类：三组划分标准

★★按范围分是重点
阶段特征
第一代面向终端的计算机网络：一台主机 + 多个终端，终端无独立处理能力
第二代计算机—计算机网络：多台主机互联，采用分组交换
第三代开放标准化网络：提出 OSI 参考模型，网络走向标准化
第四代高速网络 / Internet：光纤、宽带、多媒体应用
分类标准类型范围/说明
按覆盖范围局域网 LAN几米～几公里，一个房间/楼/校园；速度最快、误码率最低
城域网 MAN一个城市范围（几公里～几十公里）
广域网 WAN跨城市、跨国家；Internet 是最大的广域网
按拓扑结构星型、总线型、环型、树型、网状见下一节
按传输介质有线网、无线网双绞线/光纤 vs Wi-Fi/蜂窝
按使用范围公用网、专用网电信运营商 vs 企业内部（如校园内网）
范围三兄弟的口诀：LAN 一个院、MAN 一个城、WAN 一个国家。速度是反过来：LAN 最快，WAN 最慢。
考试常问"Internet 属于哪种网络"→ 广域网（WAN），而不是"城域网"。
③

五种拓扑结构（2025 简答题原题）

★★★必须能默写名字 + 各说一句优缺点
① 星型 ② 总线型 ③ 环型 ○ ○─○─○─○ ○──○ /|\ │ │ │ │ │ ○─●─○ ──┴─┴─┴── ○──○ （中心节点） （共享一条总线） （首尾相连成环） ④ 树型 ⑤ 网状 ● ○───○ / | \ / \ / \ ○ ○ ○ ○───○───○ （分级的星型） （多路径互连）
拓扑特点优点 / 缺点
星型所有节点连到一个中心节点（交换机/集线器）结构简单、易扩展；中心节点故障则全网瘫痪
总线型所有节点共享一条总线，任一时刻只能一个发布线省、成本低；易冲突、总线断了全网断
环型节点首尾相连成环，数据沿环单向（或双向）传递传输确定、无冲突；任一节点故障可能断环
树型分级的星型，有根节点与分支层次清晰、易管理；依赖上层节点
网状节点间多路径互连，可绕道可靠性最高（有冗余路径）；结构复杂、成本高
真题2025 · 简答 57（5 分）　简述计算机网络的拓扑结构（至少列出四种）。
参考答案（写全五种）：常见的网络拓扑结构有五种：①星型，所有节点连接到一个中心节点，结构简单但中心节点故障会导致全网瘫痪；②总线型，所有节点共享一条传输总线，布线简单但易发生冲突；③环型，节点首尾相连成环，传输顺序确定但单点故障影响较大；④树型，是分级的星型结构，层次清晰便于管理；⑤网状，节点间有多条路径互连，可靠性最高但结构复杂。
答法：5 分题列 5 条，每条"名称 + 一句结构 + 一句优缺点"，正好 5 分。
三个"最"要记牢：可靠性最高＝网状；结构最简单＝星型；成本最低/最省线＝总线型。
④

体系结构：OSI 七层与 TCP/IP 四层

★★★"TCP/IP 只有两个协议"是经典错项
层OSI 七层（理论模型）TCP/IP 四层（实际标准）这一层管什么
7应用层应用层为用户的程序提供服务（HTTP、FTP、SMTP、DNS）
6表示层数据格式转换、加密、压缩
5会话层建立、管理、结束会话
4传输层传输层端到端可靠传输，TCP / UDP
3网络层网际层（互联网层）IP 寻址与路由选择，路由器在这一层
2数据链路层网络接口层相邻节点间的帧传输、差错控制，交换机/MAC
1物理层比特流的传输、接口与介质，集线器/中继器
真题2024 · 判断　TCP/IP 协议族就是 TCP 和 IP 两个协议。
→ 错。TCP/IP 是一个"协议族/协议栈"，除 TCP 与 IP 外还包含 UDP、HTTP、FTP、SMTP、DNS、ARP、ICMP 等大量协议。"族"字本身就说明它是一群协议。
三个层次常识：①OSI 是理论/参考模型（七层），TCP/IP 是事实标准（四层）；②分层的好处是"各层独立、对等通信"，改一层不影响其他层；③数据在发送时逐层封装（加头），接收时逐层解封装（去头）。
七层顺序记忆：从下往上——物、数、网、传、会、表、应。取谐音："物数网传会表应"。倒过来背也可以："应用—表示—会话—传输—网络—链路—物理"。
⑤

网络设备：谁在哪一层

★★★2025 单选第 15 题：路由器
设备工作层次作用
网卡（NIC）物理层 + 链路层让计算机接入网络；每块网卡有唯一的 MAC 地址（物理地址）
中继器 / 集线器 Hub物理层放大、整形信号；共享带宽，所有端口同处一个冲突域
交换机 Switch数据链路层按 MAC 地址转发帧；每个端口独享带宽，减少冲突
路由器 Router网络层按 IP 地址选择路径、连接不同的网络（局域网↔互联网）
调制解调器 Modem物理层数字信号 ↔ 模拟信号转换（电话线上网、光纤猫）
网关 Gateway高层协议转换，连接不同体系结构的网络
无线 AP链路层提供 Wi-Fi 接入点
防火墙网络层/应用层按规则过滤进出流量（下一课细讲）
真题2025 · 单选 15（2 分）　实现不同网络之间互联、并根据 IP 地址选择路径的设备是（　）
A. 集线器　B. 交换机　C. 路由器　D. 中继器
答案：C。
三个关键词锁定路由器："不同网络之间"、"IP 地址"、"选择路径"。
对照：集线器（物理层，只放大信号）、交换机（链路层，按 MAC 转发）、中继器（物理层，延长距离）——它们都不能连接"不同网络"。
一句分层口诀：集线器在物理层、交换机在链路层、路由器在网络层——"越聪明的设备在越上层"。交换机看 MAC，路由器看 IP。
⑥

传输介质与带宽

★★bps 与 B/s 差 8 倍
介质特点
双绞线最常用（网线），有效距离约 100 米；分屏蔽/非屏蔽；超五类、六类支持千兆
同轴电缆早期有线电视/总线网络使用，现已少用
光纤带宽最高、抗电磁干扰、传输距离远；分单模（远距离）与多模（短距离）
无线Wi-Fi、蓝牙、蜂窝（4G/5G）；灵活但受干扰、安全性较弱
带宽与下载速度的换算（每年都可能考）：
带宽单位是 bps（比特/秒），下载速度单位常是 B/s（字节/秒），1 B = 8 bit。
所以100 Mbps 的宽带，理论最高下载速度 ≈ 100 ÷ 8 = 12.5 MB/s。
看到"100M 宽带下载 100MB/s"——一定是错的。
MAC 地址 vs IP 地址：MAC 是网卡的物理地址（出厂固定，48 位），用于同一局域网内寻址；IP 是逻辑地址（可配置、可变化），用于跨网络寻址。交换机认 MAC，路由器认 IP。

一、判断题（5 题）

1. 计算机网络最主要的功能是数据通信。
错误。最主要的是资源共享。
2. Internet 是当今世界上最大的广域网。
正确。
3. 星型拓扑的可靠性最高，因为结构简单。
错误。可靠性最高的是网状；星型中心节点故障会全网瘫痪。
4. TCP/IP 协议族只包含 TCP 和 IP 两个协议。
错误。还含 UDP、HTTP、FTP、DNS 等（2024 判断）。
5. 交换机和路由器都根据 IP 地址转发数据。
错误。交换机按 MAC，路由器按 IP。
