①

CPU：大脑的三件套

★★★组成与指标，年年有小分值
CPU（中央处理器） ├── 运算器 ALU —— 算术运算（+ − × ÷）+ 逻辑运算（与 或 非 比较） ├── 控制器 CU —— 取指令、译码、发控制信号，指挥全机 └── 寄存器组 —— 暂存指令、数据和地址，速度最快 CPU 与内存之间还有一层：Cache（高速缓冲存储器）
指标含义考点
主频时钟频率，单位 GHz，表示每秒的时钟周期数主频越高，单位时间内完成的指令周期越多，运算速度通常越快，但不是唯一因素
字长CPU 一次能并行处理的二进制位数32 位 / 64 位；字长越长，精度和一次处理能力越强
核心数/线程数物理核心数量、可并行的线程数量多线程可让 CPU 在等待 I/O 时去做别的事，减少闲置
缓存容量L1 / L2 / L3 的容量缓存越大，命中率越高，速度越快
指令集CPU 能执行的全部指令由硬件决定，不同架构不能直接互通
真题2025 · 判断 21　CPU 的主频越高，计算机的运行速度越快。
→ 正确。注意题干没有"唯一""一定"这类字眼，说的是"通常越快"，命题组判对。
但如果题干写成"主频是决定计算机性能的唯一指标"，就是错的——字长、缓存、核心数、硬盘速度都影响整体性能。同一句话加不加"唯一"，答案就相反。
真题2024 · 判断 4　多线程可以减少 CPU 的闲置时间。
→ 正确。一个线程等 I/O 时，CPU 可以切去执行另一个线程，等待时间被利用起来。

存储器层次：一个金字塔

★★★本课最重要的模型，判断全靠它
容量小、速度快、价格高 ┌──────────────────────────┐ │ 寄存器（CPU 内部，最快） │ ├──────────────────────────┤ │ Cache（L1/L2/L3） │ ├──────────────────────────┤ │ 内存（主存，RAM） │ ├──────────────────────────┤ │ 外存（硬盘 / U盘 / 光盘） │ └──────────────────────────┘ 容量大、速度慢、价格低
层次特点一句话定位
寄存器CPU 内部，容量极小（几十字节级）、速度最快CPU 的"手边抽屉"
Cache位于 CPU 与内存之间，容量小、速度接近 CPU解决"CPU 快、内存慢"的速度差，存放近期常用数据
内存（主存）CPU 可直接访问，断电丢失存放正在运行的程序和数据
外存（辅存）容量大、单位成本低、断电不丢，但速度慢长期存放程序和数据，需先调入内存才能被 CPU 处理
人话解释 · 为什么必须分层 如果全用和 CPU 一样快的存储，电脑会贵到买不起；如果全用硬盘，CPU 每次都要等几百个时钟周期。所以做成"少量极快的 Cache + 适量较快的内存 + 大量便宜的外存"，让常用数据待在快的地方，不常用的躺在慢的地方。这就是"局部性原理"的工程实现。
由此可以一步推出三条判断题的答案：
① 外存容量越大，读取速度越快？错——容量和速度是两回事，同代技术下容量大≠速度快。
② Cache 的作用是扩大内存容量？错——它是提速的，不是扩容的。
③ 内存比外存快但容量小？对——这正是金字塔的方向。
③

内存与外存：四个必考点

★★★2025 判断 22、24、25 连着三题都在这
对比项RAM（随机存储器）ROM（只读存储器）
读写可读可写正常只能读，写入需专用设备/特殊条件
断电后数据丢失数据保留
用途内存条，存放运行中的程序与数据存放 BIOS、固件等不需修改的程序
细分DRAM（内存条，需定时刷新）、SRAM（Cache，不需刷新）PROM / EPROM / EEPROM / Flash
2026 真题单选 第 3 题（2 分）　下列存储器中，断电后所存数据会丢失的是（　）
答案：RAM。U 盘、硬盘（外存）断电不丢，ROM 断电不丢，只有 RAM 断电即失。
这题 2025 判断第 22、24 题、2026 单选第 3 题连着考同一个点：只要问"断电"，答案一定指向 RAM。
考点结论
虚拟内存当物理内存不够时，在硬盘上划出一块空间当内存用。它不能替代物理内存，速度远低于内存；断电后虚拟内存文件也不再起作用
簇（Cluster）硬盘分配空间的最小单位，常见 4KB。所以一个 4KB 以下的文件在硬盘上也要占满一个簇——占位大于实际大小
格式化建立文件系统、划分簇；不是把磁盘"清空成空白物理盘"
缓冲区（Buffer）内存中临时存放数据的一块区域，用于协调速度差异
真题2025 · 判断 24　计算机有了虚拟内存，就不再需要物理内存了。
→ 错。虚拟内存是物理内存不够时的补充，本身就在硬盘上，速度差一到两个数量级，不能取代物理内存。
真题2025 · 判断 25　一个 4KB 的文件保存在硬盘上，占用的空间会大于 4KB。
→ 正确。硬盘按簇分配，簇通常为 4KB，文件还要占目录项等开销，所以实际占用会略大于 4KB。
真题2025 · 判断 22　外存容量越大，读写速度越快。
→ 错。容量与速度无必然关系；决定速度的是接口、转速/闪存类型、缓存等。

输入输出设备：只考"归类"

★★2025 单选第 1 题就在这
类别典型设备易错点
输入设备键盘、鼠标、扫描仪、麦克风、摄像头、手写板、条形码阅读器摄像头是输入，显示器是输出，别对调
输出设备显示器、打印机、绘图仪、音箱、投影仪投影仪只输出，不能输入
既输入又输出触摸屏、网卡、调制解调器、磁盘驱动器（可读可写）这是选择题的常客，答案通常就是"触摸屏"
真题2025 · 单选 1（2 分）　下列设备中，既是输入设备又是输出设备的是（　）
答案：触摸屏。手指点按是输入，屏幕显示是输出。
同类可归入"既输入又输出"的还有：网卡（收发数据）、调制解调器、可读写的磁盘驱动器。
设备分类与考点
打印机针式（击打、可复写多联单据）、喷墨（彩色、成本低）、激光（速度快、质量高、办公主流）
显示器主要指标：分辨率（像素数）、刷新率（Hz）、色深（位数）、尺寸
扫描仪输入设备，指标为分辨率（dpi）与色彩位数

微型计算机的主要性能指标

★★记"六大指标 + 谁能代表整机速度"
指标说明备注
字长CPU 一次处理的二进制位数越长越好，直接影响精度与能力
主频时钟频率，GHz不等于整机速度
运算速度常用 MIPS（每秒百万条指令）表示综合指标，比主频更接近"快不快"
内存容量可运行的程序规模容量不足会频繁使用虚拟内存而变慢
外存容量能装多少数据与速度无关
可靠性/可用性平均无故障时间等服务器尤其看重
一句话记法：字长看"一次能吃多少"，主频看"每秒咬几口"，MIPS 看"实际吃得多快"，容量看"能吃多久不饿"。四个词分开记，别用一个"性能好"糊过去。

2026 年真题（本课部分）

2026 年 4 月 16 日实考卷 · 考后讲评整理
2026 · 单选 第 3 题2 分　断电后数据会丢失的存储器是（　）
A. 硬盘　B. U 盘　C. ROM　D. RAM
答案：D。硬盘、U 盘是外存，断电不丢；ROM 只读、断电不丢；只有 RAM（内存条）断电即失。
这题的三个干扰项分别代表"外存、外存、只读内存"，它考的不是记忆，而是"能不能把四类存储器按断电特性排好"。
2026 · 判断 第 2 题1 分　两个二进制数按位进行逻辑与运算，题面给出运算结果为 1001，判断该结果是否正确。
答案：正确。
逻辑与的规则：1∧1=1，其余（1∧0、0∧1、0∧0）全为 0——"有 0 则 0"。所以只要两个数中某一位有 0，该位结果就是 0；只有两位都是 1，该位才是 1。
命题意图：把算术运算与逻辑运算混在一起考。注意区分——算术加法 1+1=10（进位），逻辑与 1∧1=1（不进位）。
2026 在本课给出的信号：①"断电丢不丢"是必考中的必考，2025 判断 22/24、2026 单选 3 连考；②逻辑运算开始以判断题形式出现，且专门和算术运算对照着考。这两条都是"懂了就不会错"的题，别丢。

本课必背 12 条

进考场前扫一眼
#内容
1CPU = 运算器 + 控制器（另有寄存器组）；运算器做算术与逻辑运算，控制器指挥全机
2CPU 指标：主频（GHz）、字长、核心数、缓存容量、指令集；主频高不等于整机快
3存储器金字塔（快→慢）：寄存器 → Cache → 内存 → 外存；容量与速度反向
4Cache 解决 CPU 与内存的速度差，靠"局部性"提速，不扩容
5RAM 可读写、断电丢失；ROM 只读、断电保留（存 BIOS）
6DRAM 需刷新（内存条）；SRAM 不需刷新（Cache）
7虚拟内存 = 硬盘上划出的空间，不能替代物理内存，速度慢
8硬盘按簇分配空间（常见 4KB），小文件也占满一个簇
9外存：断电不丢、容量大、速度慢；容量大小与读写速度无必然关系
10触摸屏、网卡、调制解调器属"既输入又输出"；投影仪只输出
11性能指标：字长、主频、运算速度（MIPS）、内存容量、外存容量、可靠性
12运算对照：算术 1+1=10；逻辑与 1∧1=1，有 0 则 0

一、判断题（5 题）

1. ROM 中的信息断电后不会丢失，RAM 中的信息断电后会丢失。
正确。这正是两者最本质的区别。
2. Cache 的作用是扩大内存的容量。
错误。Cache 容量很小，作用是缓解 CPU 与内存的速度差。
3. 计算机的虚拟内存是在内存条上划分出来的。
错误。虚拟内存在硬盘上。
4. 外存储器的容量越大，其读写速度就越快。
错误。容量与速度无关。
5. 硬盘上一个 3KB 的文件实际占用的空间可能大于 3KB。
正确。按簇分配，最小占用一个簇（常见 4KB）。

二、单项选择题（5 题）

6. 下列设备中，既是输入设备又是输出设备的是（　）
A. 键盘　B. 显示器　C. 触摸屏　D. 打印机
C。2025 单选第 1 题同款。
7. CPU 由（　）组成
A. 运算器和存储器　B. 运算器和控制器　C. 控制器和存储器　D. 寄存器和外存
B。
8. 计算机中用于解决 CPU 与内存速度不匹配问题的部件是（　）
A. 寄存器　B. Cache　C. 硬盘　D. 虚拟内存
B。Cache 是关键。虚拟内存解决的是"容量不够"，不是"速度差"。
9. 下列存储器中，断电后数据会丢失的是（　）
A. 硬盘　B. U 盘　C. ROM　D. RAM
D。2026 单选第 3 题原题。
10. 表示计算机运算速度的常用指标是（　）
A. MIPS　B. dpi　C. Hz 只表示分辨率　D. GB
A。MIPS＝每秒百万条指令；dpi 是打印/扫描分辨率，Hz 是频率，GB 是容量。

1。逻辑与"有 0 则 0，全 1 才 1"，不进位；算术加法 1+1 才是 10。
