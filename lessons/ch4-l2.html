Internet 的来历

★三个年份/名字够用
节点要点
ARPANET1969 年美国国防部高级研究计划局建立，最初只有 4 个节点——Internet 的前身
TCP/IP1983 年成为 ARPANET 的正式协议，为 Internet 的统一互联奠定基础
Internet 名称由"interconnected networks"（互联的网络）而来，不是单一网络，而是"网络的网络"
中国接入1994 年我国正式接入国际互联网（此前 1987 年发出第一封电子邮件）
三个"第一"别混：1969 ARPANET（前身，4 节点）；1983 TCP/IP 成为标准；1994 中国正式接入。
"Internet 是网络的网络"这句话常在判断里出现，是对的。它由成千上万个局域网、城域网、广域网互联而成，没有一个"总开关"。

IP 地址：四段十进制与五类地址

★★★看首字节就能判类
IPv4 地址 = 32 位二进制，写成 4 段十进制（每段 0～255） 例：192.168.1.100 └┬─┘ └┬┘ └┬┘ └─┬─┘ 网络部分 主机部分（由子网掩码划分） 每一段 8 位 → 2⁸ = 256 种取值（0～255） IPv6 = 128 位，写成 8 组十六进制，如 2001:0db8::1
类别首字节范围默认掩码用途
A 类1 ～ 126255.0.0.0（/8）超大型网络，可容纳极多主机
B 类128 ～ 191255.255.0.0（/16）中型网络
C 类192 ～ 223255.255.255.0（/24）小型网络（校园、企业最常见）
D 类224 ～ 239—组播（多播）地址，不分配给主机
E 类240 ～ 255—保留实验用
判类口诀：看第一段数字落在哪个区间——1～126 是 A，128～191 是 B，192～223 是 C，224 以上是 D/E。
例：10.0.0.1→A 类；172.16.5.4→B 类；192.168.3.10→C 类。
特殊地址含义
127.0.0.1本机回环地址（localhost），用于本机测试
255.255.255.255广播地址（发往本网所有主机）
私有地址10.x.x.x、172.16～172.31.x.x、192.168.x.x——只在局域网内部使用，不能直接在公网路由
0.0.0.0表示"本网络/任意地址"
子网掩码的作用：用一串"1"标出网络号占几位，"0"标出主机号占几位。IP 与掩码按位与得到网络号。255.255.255.0 表示前 24 位是网络号、后 8 位是主机号。

一台 C 类网络能连多少台主机（2026 真题）

★★★2n−2 的算法
2026 真题单选 第 17 题（2 分）　一个 C 类 IP 地址段最多可以容纳的主机数是（　）
A. 256　B. 255　C. 254　D. 128
答案：C。
为什么是 254 而不是 256 C 类默认掩码 255.255.255.0，前 24 位是网络号，后 8 位是主机号。
8 位主机号共有 28 ＝ 256 种组合，但其中两个不能用：
　· 主机号全 0 → 代表网络本身（网络地址，如 192.168.1.0）
　· 主机号全 1 → 代表广播地址（如 192.168.1.255）
所以可用主机数 ＝ 28 − 2 ＝ 254。
通用公式：可用主机数 ＝ 2主机位数 − 2。
A 类主机位 24 → 224−2 ≈ 1677 万；B 类主机位 16 → 65 534；C 类主机位 8 → 254。
看到选项里给"256"，那就是故意留给"忘了减 2"的人。
反过来也要会：题目问"哪个地址不能分配给主机"，答案通常是网络地址（末段为 0）或广播地址（末段为 255）（C 类情况下）。192.168.1.0 与 192.168.1.255 都不能给主机用。

域名与 DNS：给人看的地址

★★★2025 判断第 26 题就在这
URL 拆解（考试常让"指出各部分"） https:// www.scedu.gov.cn :8080 /news/2026.html 协议 域名（主机名+二级+顶级） 端口 路径与文件名 域名的层级：从右往左读，越往右级别越高 www . scedu . gov . cn │ │ │ └─ 顶级域（.cn 国家） │ │ └─────── 二级/三级域（gov 政府） │ └────────────── 二级域（scedu 单位名） └───────────────────── 主机名（www 表示网站服务器）
顶级域含义顶级域含义
.com商业机构.edu教育机构
.gov政府机构.org非营利组织
.net网络服务.cn中国
.mil军事.jp / .uk日本 / 英国
真题2025 · 判断 26　访问一个网站时，既可以使用域名，也可以直接使用它的 IP 地址。
→ 正确。域名只是 IP 的"别名"，DNS 把它翻译成 IP；直接输入 IP 同样能打开网站（只是记忆不便、且一个 IP 上可能挂多个网站时会有差异）。
记住"域名→IP"的方向：DNS 做的是域名解析，即"把域名翻译成 IP"，不是反过来。
三个"不一定"（判断题素材）：①一个域名可以对应多个 IP（大型网站多台服务器）；②一个 IP 可以对应多个域名（虚拟主机）；③域名与 IP 不是一一对应。凡是说"域名与 IP 一一对应"的，一律错。

Internet 的主要服务

★★★协议与功能必须一一对上
服务协议说明与考点
WWW 万维网HTTP / HTTPS基于超文本的信息浏览；B/S 结构（浏览器—服务器）；HTTPS 是加密版，默认端口 443
电子邮件发：SMTP
收：POP3 / IMAP		地址格式用户名@域名；可带附件；"发信用 SMTP、收信用 POP3"必须分清
文件传输FTP在不同主机之间上传/下载文件；可设匿名登录
远程登录Telnet / SSH登录到远程主机并像本地一样操作；SSH 加密更安全
域名解析DNS域名 ↔ IP 的翻译服务
网络诊断ping / ipconfigping 测试两台主机是否连通、往返时延；ipconfig 查看本机 IP 配置
真题2025 · 单选 14（2 分）　用于测试本地主机与目标主机之间网络是否连通的命令是（　）
A. ftp　B. ping　C. telnet　D. http
答案：B。
四个选项各管一件事：ftp 传文件、ping 测连通、telnet 远程登录、http 传网页。"是否连通/能不能通"这句话只对应 ping。
协议速记：HTTP 看网页、SMTP 发邮件、POP3 收邮件、FTP 传文件、DNS 翻域名、ping 试连通、SSH 远程管。
邮件那条单独记："S" 是 Send（发），"POP" 是收到信箱里（收）。
B/S 与 C/S 的区别（可能出选择）：B/S＝浏览器/服务器（不用装客户端，如网银、教务系统）；C/S＝客户端/服务器（要装软件，如 QQ、微信桌面版）。WWW 属于 B/S。

信息检索：把搜索变准的五个符号

★考纲"了解"，认得用法即可
检索方式作用例子
空格 / AND同时包含多个关键词（缩小范围）四川 专升本 计算机
OR包含任一个（扩大范围）专升本 OR 专插本
−（减号）排除某词苹果 -手机
"引号"精确匹配整句"四川省普通高校专升本考试要求"
site:限定站点site:edu.sc.gov.cn 专升本
filetype:限定文件类型filetype:pdf 计算机基础 考纲
搜索引擎两类：全文搜索引擎（按关键词抓取网页全文，如百度、Google）与目录/分类搜索引擎（人工分类目录）。另有元搜索、垂直搜索（学术、图片、视频）。
检索三原则：先精确后宽泛（先用引号与 site 缩小）；换词比换页快（同义词、学名、英文名）；看来源辨真伪（优先官网、权威机构、正式出版物）。
