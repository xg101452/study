文档的基本操作

★★快捷键 + 扩展名，两件事
操作常用方式要点
新建Ctrl + N / 双击图标 / 快速访问工具栏新建的是空白文档，默认名"文档1"；基于 normal.dotm 模板，所以默认字体是宋体五号
打开Ctrl + O / 双击文档 / 最近使用的文件可打开 .docx / .doc / .pdf / .txt 等；快速访问工具栏可自定义增删按钮
保存Ctrl + S保存到原位置原文件名；首次保存会弹出"另存为"对话框；默认每 10 分钟自动保存一次（可改）
另存为F12换位置/文件名/格式，原文件保持不变；可设打开密码与修改密码
关闭Ctrl + F4（=Ctrl + W）只关文档；Alt + F4 退出程序有未保存修改会提示"是否保存"
打印Ctrl + P可设置份数、范围、单双面
新建文档的两个隐藏考点 默认名 "文档1"（不是"新建文档"） 默认模板 normal.dotm（启用宏的模板；不是 .dotx） 默认字体 宋体 · 五号（因为继承自 normal.dotm）

保存 vs 另存为：什么时候一样，什么时候不一样

对比保存另存为
首次完全一样：都会弹出"另存为"对话框，让你选路径、填文件名
之后再改直接覆盖原文件，文件名、路径、类型都不变生成新文件，原文件不受影响；可改名、改路径、改类型
密码不能设「工具 → 常规选项」可设打开密码（没密码打不开）和修改密码（没密码只能只读）
Word 文档的常见格式 .docx 默认格式（2007 以后） ← 考"默认扩展名"就答它 .doc 旧版格式（97-2003） .dotx 模板文件 .dotm 启用宏的模板（normal.dotm 就是它） .docm 启用宏的文档 .pdf 固定版式，不易被改动 .txt 纯文本，丢失所有格式
三个必踩的坑：①"Word 文档的默认扩展名是 .doc"——错，是 .docx（.doc 是旧版）；②"另存为会覆盖原文件"——错，另存为产生新文件；③"关闭文档等于关闭 Word 程序"——错，Ctrl+F4 / Ctrl+W 只关当前文档，Alt+F4 才退出 Word。

文本编辑与"选定"（本节是 2026 的考点）

★★★左侧选定区的三击，一定要背准
在左侧选定区的操作选定的范围
单击选定这一行
双击选定这一段
三击选定整篇文档
2026 真题单选 第 6 题（2 分）　在 Word 文档左侧的选定区三击鼠标，将选定（　）
A. 一行　B. 一段　C. 一句　D. 整篇文档
答案：D。
口诀：一击一行、二击一段、三击全篇。这一组是"数次数"的题，把三个数字和三个范围绑在一起背，就不会串。
其他选定方式选定的范围
拖动鼠标从起点到终点的连续文本
双击某个词选定该词（英文按词、中文按连续字串）
Ctrl + A全选
Shift + 单击从光标处扩展到单击处
Alt + 拖动纵向（列块）选择
Ctrl + 单击正文选中光标所在的一句（以句号断句）
F8 连按逐级扩展：词组 → 句子 → 段落 → 全文；按 Esc 退出

录入与光标定位：这些小键常被单选考

按键作用
Caps Lock大写锁定键：只影响字母，不影响数字和符号
Shift上档键：小写状态下按字母出大写；大写锁定下按字母反而出小写（反向）
Ctrl + 空格系统默认中英文切换；Ctrl + Shift 切换不同输入法
Home / End光标到本行行首 / 行尾；Ctrl + Home / Ctrl + End 到整篇文档开头 / 结尾
Page Up / Page Down向上 / 向下翻一页
编辑动作说明
插入 / 改写按 Insert 键切换。插入＝新字挤进去；改写＝新字覆盖后面的字。状态栏显示"改写"即为改写模式
删除Backspace 删光标前一个字符；Delete 删光标后一个字符
复制 / 移动Ctrl+C / Ctrl+X 后 Ctrl+V；或直接拖动（按住 Ctrl 拖动＝复制）
查找 / 替换Ctrl+F 查找、Ctrl+H 替换；可替换文字、格式，支持通配符
撤销 / 恢复Ctrl+Z 撤销；Ctrl+Y 恢复（重做）

查找、替换、定位：三个键别混

功能快捷键要点
查找Ctrl + F弹出导航窗格，高亮所有匹配；也能查找图形、表格、公式
替换Ctrl + H可替换文字、格式（如全文 4 号字改成蓝色下划线）、特殊格式
定位Ctrl + G跳到指定页、节、行、书签、批注、图形、表格
特殊替换四种常见考法 手动换行符 → 段落标记 （软回车变硬回车） 任意字母 / 任意数字 → 设好格式的空内容 （批量改字体颜色） 两个段落标记 → 一个 （删多余空行，反复替换到无匹配） 图形 → 留空 （一次删掉全文图片）
剪贴板次数：Word 内置剪贴板最多存 24 次复制内容；Win7 系统剪贴板只留最近 1 次。题目问"Word 剪贴板可保存多少次"，答 24。
Ctrl+Y 的双重身份：刚做过撤销 → 它是恢复；没做过撤销 → 它是重复上一次输入。
最容易混的一对：Backspace 删左边（往前删），Delete 删右边（往后删）。题目问"删除光标前一个字符"，答 Backspace。

字符格式：只管"字"长什么样

★★字形效果可以叠加
属性说明
字体宋体、黑体、楷体、Times New Roman 等；中英文可分别设置
字号中文字号（初号、小初、一号…八号）与磅值（pt）两套；字号越大字越大（与"号"的序号相反）
字形常规、加粗、倾斜、加粗倾斜——四种可组合
下划线 / 删除线可设线型与颜色
颜色 / 突出显示字体颜色 vs 底纹突出显示，两者不同
字符间距加宽/紧缩，按磅计
上标 / 下标如 x2、H2O
首字下沉段首第一个字放大并下沉；入口在插入 → 文本 → 首字下沉，效果作用于段落（详见第 2 课）
真题2025 · 判断 31　在 Word 中设置文字格式时，"倾斜"与"加粗"不能同时使用。
→ 错。字形有"加粗倾斜"这一组合项，同一个字可以既粗又斜，还可以再加下划线。
反过来也要记：字体、字号、字形、颜色可以叠加，但它们都属于"字符格式"，只作用于选中的文字——如果没选中就设置，只影响光标之后新输入的字。
"选中 vs 未选中"这个细节能出判断：不选中任何文字而直接改字体，已输入的文字不变，只有后面新打的字用新字体。想改已有的字，必须先选中它。

字符格式的三条设置路径（操作题按这个顺序答）

路径怎么调出覆盖范围
浮动工具栏选中文字后，文字右上角自动浮出小工具栏只能做基础字符设置
功能区"字体"组开始 → 字体，直接点按钮常用字符格式
字体对话框三种调法：①"字体"组右下角的对话框启动器　②Ctrl + D　③选中文字右键 → 字体最全，字符间距等高级项只有这里有
字号两套体系怎么比大小 磅值（阿拉伯数字） 数字越大，字越大 五号 = 10.5 磅 中文字号（中文数字）数字越大，字越小 一号 > 二号 > 三号 > 四号 > 五号 跨体系比较的桥梁 14 磅 = 四号，比默认的五号大
只有字体对话框里才有位置
着重号"字体"选项卡 → 所有文字 → 着重号（给字加小圆点标重点）
单删除线 / 双删除线"字体"选项卡 → 效果
上标 / 下标"字体"选项卡 → 效果（化学式、数学式常用）
字符间距（加宽/紧缩）、位置（提升/降低）"高级"选项卡　★ 考评频率高
"开始 → 字体"组里要认全的按钮 加粗 Ctrl+B（Bold） 倾斜 Ctrl+I（Italic） 下划线 Ctrl+U（Underline） 删除线 上标 x² 下标 H₂O 字体颜色 清除格式 增大字号 / 减小字号 突出显示文本 字符边框 字符底纹 带圈字符 拼音指南 更改大小写 文本效果（阴影 / 倒影 / 发光）
字符格式三个高频陷阱：①同时选中"宋体 + 楷体"两种字体的文字，字体下拉框显示空白，不是显示其中任意一种；②字体对话框里没有"对齐方式"——对齐属于段落格式，问"字体对话框不能设置什么"就答对齐；③字符间距加宽后，每行能容纳的字数变少。
操作题的满分写法（三级结构）：先写选项卡，再写功能组，最后写按钮。例如"选中文字 → 开始选项卡 → 字体组 → 加粗按钮"。只写"点加粗"会被扣分。所有软件操作都遵循先选中、后操作。

段落格式：缩进、对齐、行距

★★★2025 填空、2026 单选都在这一节
属性取值与说明
对齐左对齐、居中、右对齐、两端对齐（正文最常用，使左右两端都整齐）、分散对齐
首行缩进只把第一行往里缩（中文正文常见"首行缩进 2 字符"）
悬挂缩进第一行不缩，其余各行往里缩（项目列表常用）
行距单倍、1.5 倍、2 倍、最小值、固定值、多倍行距 六种
段前 / 段后间距段与段之间的距离，与行距不同
项目符号 / 编号给段落加"●"或"1. 2. 3."，属段落格式
边框 / 底纹可加在文字上，也可加在段落上
真题2025 · 填空 49（3 分）　在 Word 中，使段落的第一行向右缩进、其余各行保持不变的段落格式称为 ______。
答案：首行缩进。
对照：若"第一行不变、其余各行缩进"，那是悬挂缩进。两个名字只差两个字，含义正好相反——"首行"缩的是第一行，"悬挂"缩的是除第一行以外。
2026 真题单选 第 7 题（2 分）　在 Word 中将段落行距设置为 1.2 倍，行距列表中显示为（　）
A. 单倍行距　B. 1.5 倍行距　C. 多倍行距　D. 固定值
答案：C。
Word 的行距下拉列表只预置"单倍 / 1.5 倍 / 2 倍 / 最小值 / 固定值 / 多倍行距"六项，凡是不等于 1、1.5、2 的倍数，一律归入"多倍行距"，所以 1.2 显示为"多倍行距 1.2"。
这条题的思路值得记：它不考你会不会点按钮，而考你知不知道列表里有哪些固定项。记住六个名字，就能反推出任意数值的归类。
行距三兄弟别混："单倍/1.5 倍/2 倍"是按行的倍数；"固定值"是按磅写死（如 20 磅），字号变大也不会自动撑开；"最小值"是给一个下限。题目说"行距固定为 20 磅"→ 选固定值。

段落标记：一段格式的"仓库"

段落标记（¶）的四条必考规则 ① 段落标记里保存着本段的全部段落格式 ② 要复制一段的格式，必须把段末的段落标记一起选中再复制 ③ 删掉两段之间的段落标记 → 两段合并，合并后沿用上一段的格式 ④ 光标在某段内按回车，新段自动继承该段的格式
两种回车按键通配符效果
硬回车（段落标记）Enter^p分段，另起一段
软回车（手动换行符）Shift + Enter^l只换行，仍属同一段
显示/隐藏段落标记：开始 → 段落 → "显示/隐藏编辑标记"按钮；或 文件 → 选项 → 显示 → 勾选"显示所有格式标记"。
批量删空行：Ctrl + H，查找 ^p^p 替换为 ^p，反复点"全部替换"直到提示找不到。

补齐：默认对齐、左右缩进与行距细节

项目要点
默认对齐方式两端对齐（不是左对齐）；两端对齐时最后一行仍然靠左　★ 最容易判错
分散对齐把整行字符均匀撑满整行，字与字的间距相等
左缩进 / 右缩进整段所有行一起右移 / 左移，改的是整段的左右边界（与首行、悬挂缩进并列，共四种缩进）
固定值行距按磅写死；字号变大时行距不会跟着撑开，会出现文字显示不全　★
段前 / 段后间距单位默认是"行"，也可手动改成"磅"
调整行距的效果只改行与行的距离，不改变每行能容纳的字数　★
对比项目符号编号
标识类型字符，也可以用自定义图片只能用有顺序的字符，不能用图片　★ 高频易错
调整层级按 Tab 降一级，按 Shift + Tab 升一级
自定义符号样式、图片编号格式（1,2,3 / 一,二,三 / 甲,乙,丙 / A,B,C）；右键"设置编号值"可改起始序号
段落对话框 → "换行和分页"选项卡（正式出版物、法律文书常用） 孤行控制 不让段落的首行单独留在上页末尾、末行单独跑到下页开头 段中不分页 整段不跨页 与下段同页 本段与下一段必须排在同一页 段前分页 本段之前自动分页 取消行号 / 取消断字
边框与底纹的边界：入口是 开始 → 段落 → 边框下拉 → "边框和底纹"，可设方框/阴影/三维、内外框用不同线型，应用范围默认整个段落。底纹只能给文字和段落，不能给页面；页面要背景色得用"页面颜色"填充。段落还能按拼音升序/降序排序。

页面设置与视图：纸张、边距、页眉页脚、分页、五大视图

★★2025 判断第 32 题：页码能放页眉吗
项目要点
纸张大小默认 A4（210×297 mm）；还有 A3、B5、Letter 等
纸张方向纵向 / 横向
页边距上、下、左、右四个边距；装订线另算
页眉 / 页脚每页顶部/底部的重复区域，可放文字、图片、页码、日期
页码可放在页眉或页脚，可设起始页码与格式（1,2,3 或 Ⅰ,Ⅱ,Ⅲ）
分栏把一页分成两栏或多栏（报刊样式）
文档背景“页面布局→页面背景”三件套：水印（文字/图片，淡化后衬于文字下方）、页面颜色（纯色/渐变/纹理/图片）、页面边框（线条或艺术型）
分页符强制从下一页开始（Ctrl+Enter）
分节符把文档分成若干"节"，各节可设不同的页面格式（如封面不编页码）
真题2025 · 判断 32　Word 中页码只能插入到页脚，不能插入到页眉。
→ 错。页码页眉、页脚都能放；"插入页码"命令默认放在页脚中部，但用户可以自己挪到页眉。
这个陷阱的套路："只能/必须/一定"出现在位置类描述里，基本可以判错。
分页 vs 分节，一句话分清：分页符只换页，页面设置还是同一套；分节符换"章"，可以让前后两节各用各的纸张方向、页边距、页眉页脚。要"封面不要页码、正文从 1 开始"，必须用分节符。

页眉页脚与页码：五个易错点

项目要点
页眉下面那条横线它是页眉段落的下边框线，不是下划线；去掉的方法：开始 → 段落 → 边框 → 无边框　★
默认生效范围在任意一页加页眉/页脚，默认所有页显示相同内容
奇偶页不同 / 首页不同进入页眉页脚编辑状态后勾选，可分别设置（书籍印刷、封面常用）
页码在哪些视图可见只有页面视图和打印预览能看到页码　★
页码能放的位置页面顶端、底端、页边距，还能放在任意光标处，不限于页眉页脚　★
页码格式与起始值可用 1,2,3 / A,B,C / 甲,乙,丙 / 一,二,三；起始页码可自定义，不必从 1 开始
进出编辑状态页面视图下双击页眉/页脚区进入，双击正文区退出

页面设置对话框的四个选项卡

页面布局 → "页面设置"组右下角的对话框启动器 页边距 上下左右边距 + 装订线 + 纸张方向（默认纵向） 纸张 默认 A4（21 cm × 29.7 cm），可改 A3 / B5 / Letter 版式 页眉页脚边距、奇偶页不同、首页不同、行号、边框 文档网格 指定每行字数和每页行数 ← 最容易被漏掉的考点
页边距 ≠ 段落缩进（必考辨析）：页边距从"纸张边缘"量到"正文编辑区边界"，管整篇文档；段落缩进从"正文编辑区边界"量到"段落首字符"，只管选中的段落。两个起点完全不同，不能混。

四种分隔符：分页、分栏、换行、分节

分隔符插入方法关键规则
分页符①Ctrl + Enter　②页面布局 → 分隔符 → 分页符　③插入 → 分页手动分页符可选中按 Delete 删除；自动分页符删不掉，只能删减内容　★
分栏符页面布局 → 分隔符 → 分栏符后面的内容直接跳到下一栏
自动换行符Shift + Enter只换行不分段（就是软回车）
分节符页面布局 → 分隔符 → 分节符四类：下一页、连续、偶数页、奇数页　★
分节符四类的区别 下一页 分节 + 分页，新节从下一页开始 连续 只分节不分页，同一页里就能换一套页面设置 偶数页 新节从下一个偶数页开始 奇数页 新节从下一个奇数页开始 新建文档默认只有 1 个节；同一节内所有页共用一套页面设置
分栏的三条规则：①只对选中的内容生效，不必整篇分栏；②默认等宽，取消"栏宽相等"就能做不等宽分栏；③栏与栏之间可以加分隔线。

五大视图、格式刷与样式模板

视图特点与限制
页面视图默认视图，所见即所得；页眉页脚、分栏、页码都能看到
阅读版式视图默认双页显示，默认不能编辑（开启"允许键入"后才能改），可加批注
Web 版式视图看文档转成网页后的效果；不显示页眉页脚
大纲视图按标题层级折叠/展开，长文档理框架专用；可设显示级别
草稿视图只显示文字，不显示图片等对象，占用资源最少
五大视图记忆口诀：我打月页草 我 → Web 版式 打 → 大纲 月 → 阅读版式 页 → 页面 草 → 草稿 切换入口全部在"视图"选项卡下
工具规则
格式刷只复制格式，不复制内容；单击用一次，双击可连续用，按 Esc 退出；快捷键 Ctrl+Shift+C 复制格式、Ctrl+Shift+V 粘贴格式
内置样式可修改，不可删除；改完全文用到该样式的地方一起更新
自定义样式可修改，也可删除
模板模板扩展名 .dotx；Word 的默认模板是 normal.dotm

五、简答题（1 题）

27. 简述“页边距”与“段落缩进”的区别。（4 分）
①页边距：从纸张边缘量到正文编辑区边界的留白距离，作用于整篇文档；②段落缩进：从正文编辑区边界量到段落首字符的距离，只作用于选中的段落；③两者起算点不同，属于不同层级的排版参数，不能混。

六、操作题（1 题）

28. 把文档标题设为“黑体、三号、加粗、居中”，写出规范的操作步骤。（4 分）
①选中标题文字；②开始选项卡 → 字体组 → 字体框选“黑体”、字号框选“三号”、点加粗按钮；③开始选项卡 → 段落组 → 点居中按钮。
评分要点：必须按“选项卡 → 功能组 → 按钮”三级结构描述，并体现“先选中、后操作”。
