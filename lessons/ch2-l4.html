图标、窗口与活动窗口

★★2025 单选第 3 题就在这里
对象要点
快捷方式指向某个程序的"指针"，图标左下角有小箭头。删除快捷方式不会删除原文件；反之删了原文件，快捷方式就失效
文件图标图标形状由扩展名决定（关联程序），改扩展名可能导致图标变化、文件打不开
窗口组成标题栏、菜单栏/功能区、地址栏、工作区、状态栏、滚动条、边框
活动窗口同一时刻只有一个活动窗口（标题栏高亮）；切换用 Alt+Tab
窗口按钮最小化（到任务栏）、最大化/还原、关闭；关闭 = 结束该程序
真题2025 · 单选 3（2 分）　要将当前活动窗口的画面复制到剪贴板，应按（　）
答案：Alt + PrintScreen。
对照记忆：PrintScreen 单独按 → 整个屏幕；Alt+PrintScreen → 只抓当前活动窗口。
注意"复制到剪贴板"和"保存为图片文件"是两件事：按键只是进剪贴板，还要粘贴到画图/文档里才成为文件。
为什么只考活动窗口？因为"同一时刻只有一个活动窗口"本身就是考点。题目若说"可以同时有多个活动窗口"，一律判错。

菜单与鼠标键盘操作

★知道有哪几类菜单即可
菜单类型打开方式说明
下拉菜单单击菜单栏上的项目窗口顶部的"文件/编辑/视图"
快捷菜单右键单击对象与"上下文"相关，对象不同内容不同
控制菜单Alt + 空格窗口左上角图标对应的菜单（移动/大小/关闭）
级联菜单菜单项右侧有三角/箭头展开下一级
鼠标操作典型用途
单击（左键）选中对象、按下按钮
双击（左键）打开文件/文件夹、运行程序
右击弹出快捷菜单
拖动移动对象；按住 Ctrl 拖动＝复制，按住 Shift 拖动＝移动
拖动那条别记反：同一磁盘内拖动＝移动，跨磁盘拖动＝复制；加 Ctrl 强制复制，加 Shift 强制移动。考"复制"时最常见的正确项就是"按住 Ctrl 拖动"。

资源管理与任务管理

★★2026 单选第 5 题考的就是文件夹结构
资源管理器（此电脑） └── 桌面 / 文档 / 下载 … └── 盘符（C:、D:、E: …） └── 文件夹 └── 子文件夹 └── 文件 这就是"树形结构"（倒置的树）：根在最上，逐级向下分叉 ——不是"网状"，也不是"线性/链式"
2026 真题单选 第 5 题（2 分）　Windows 中文件系统的组织结构是（　）
答案：树形结构（倒置的树）。
干扰项常写成"网状结构""线性结构""环状结构"。判断依据很简单：一个文件只能有一个上级文件夹，但一个文件夹可以有很多下级——单向一对多，正是树。
工具作用与考点
任务管理器查看正在运行的进程与应用程序、CPU/内存占用；结束任务用于关闭无响应的程序。打开方式：Ctrl+Shift+Esc，或 Ctrl+Alt+Del 后选择
控制面板系统设置中心：用户账户、程序和功能（卸载）、网络、显示、日期时间等
回收站存放被删除的文件/文件夹；可还原、可清空、容量大小可设置；U 盘和网络位置的文件删除不进回收站
剪贴板内存中的一块临时区域，复制/剪切的内容暂存于此；关机后内容消失
真题2025 · 判断 28　回收站的大小是固定的，用户不能修改。
→ 错。右键回收站 → 属性，可以按驱动器分别设置容量上限，超过上限时会提示或自动清除最旧的文件。

文件管理：命名、路径、通配符

★★★本课最"送分"也最容易漏的地方
项目规则考点
文件名组成主文件名 . 扩展名，如 报告.docx扩展名标识类型，改扩展名不会真正改变文件内容
命名规则最长 255 个字符；不区分大小写；不能含 \ / : * ? " < > |；同一文件夹内不能同名"ABC.txt"与"abc.txt"是同一个文件
通配符* 代表任意多个字符；? 代表任意一个字符*.docx＝所有 docx；a?.txt＝a 开头且后面一个字符的 txt
文件属性只读（不能修改保存）、隐藏（默认不显示）、存档设了只读后修改会被拒绝
路径绝对路径从盘符开始（D:\资料\笔记.docx）；相对路径从当前位置起算"\"是目录分隔符
扩展名类型扩展名类型
.exe可执行程序.docx / .xlsx / .pptxWord / Excel / PPT 文档
.txt纯文本.jpg / .png / .bmp图像
.mp3 / .wav音频.mp4 / .avi视频
.zip / .rar / .7z压缩包.html / .htm网页
通配符记一句：星号管"一串"，问号管"一个"。
例：要找"所有以 a 开头的文本文件"，写 a*.txt；要找"文件名只有两个字符的 bmp"，写 ??.bmp。
三个高频判断：①"Shift+Delete 删除的文件能从回收站还原"——错，它不进回收站；②"U 盘上删除的文件在回收站里"——错，U 盘不走回收站；③"文件扩展名改变后，内容也随之改变"——错，扩展名只影响关联程序。

2026 年真题（本课部分）

2026 年 4 月 16 日实考卷 · 考后讲评整理
2026 · 单选 第 4 题2 分　直接关闭当前活动窗口的快捷键是（　）
A. Ctrl + Alt + Delete　B. Alt + Tab　C. Alt + F4　D. Ctrl + F4
答案：C。
三个干扰项各管一件事：Ctrl+Alt+Delete 打开安全界面（可进任务管理器）；Alt+Tab 切换窗口；Ctrl+F4 关闭当前文档/子窗口，不退出程序。
一句话区分：Alt+F4 关"整个程序"，Ctrl+F4 关"程序里的一个窗口"。
2026 · 单选 第 5 题2 分　Windows 中文件系统的组织结构是（　）
A. 网状结构　B. 树形结构　C. 线性结构　D. 环状结构
答案：B。
判断依据：一个文件只能属于一个文件夹，一个文件夹可以有多个子文件夹——一对多的单向关系，就是树。资源管理器的左侧导航窗格就是这棵"倒置的树"。
2026 在本课给出的信号：两道题都落在"最基础的常识"上——一个快捷键、一个结构名。这类题不需要推理，只需要没漏背。所以本课的快捷键表和"树形结构"这四个字，必须做到看题即答。

一、判断题（5 题）

1. 删除桌面上某程序的快捷方式，该程序就被卸载了。
错误。快捷方式只是指针，删它不影响原程序。
2. Windows 中同一时刻可以有多个活动窗口。
错误。只能有一个。
3. 回收站的大小用户可以自行设置。
正确。右键回收站→属性可按驱动器设置（2025 判断 28）。
4. 文件的扩展名改变了，文件内容也随之改变。
错误。扩展名只决定关联程序与图标，不改内容。
5. Windows 文件名不区分大小写，ABC.txt 与 abc.txt 是同一个文件。
正确。
