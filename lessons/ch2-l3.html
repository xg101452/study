①

软件与软件系统

★★先把"三要素"钉死，后面才不会错
软件 = 程序 + 数据 + 文档 （三者缺一不可，不是"只有程序"） 软件系统 ├── 系统软件（由厂商提供，管理硬件、支撑应用） │ ├── 操作系统 ← 最基本、最核心 │ ├── 语言处理程序（汇编/编译/解释程序） │ ├── 数据库管理系统（DBMS） │ └── 各类服务性程序（诊断、备份、杀毒等） └── 应用软件（为解决某一具体问题而开发） ├── 通用应用软件：Office、浏览器、压缩工具 └── 专用应用软件：CAD、财务软件、教务系统
对比系统软件应用软件
目的管理、调度硬件，为其他软件提供运行环境解决用户的某一具体问题
来源由厂商/专业公司提供可由用户或软件公司开发
典型Windows、Linux、编译程序、DBMSWord、Excel、微信、浏览器
地位没有它，应用软件无法运行没有它，机器能跑但"没事可干"
两个判断题模板：①"软件就是程序"——错（还有数据和文档）；②"系统软件是用户为解决某个问题开发的"——错（那是应用软件）。这两句话 2026 年还以多选的形式出现过，属于年年可考的老陷阱。
②

操作系统是什么：三个身份

★★★"最基本"三个字是一定要记住的
一句话定义（背下来） 操作系统是管理计算机硬件与软件资源、控制程序运行、并为用户提供操作接口的系统软件，是最基本的系统软件，是用户与计算机之间的接口。
身份含义
资源管理者管处理器、内存、设备、文件——这就是"五大功能"的来源
用户接口让用户能操作机器：命令行、图形界面、系统调用
运行平台所有应用软件都跑在 OS 之上，OS 提供运行环境
层次结构（从下往上） 硬件 → 操作系统 → 其他系统软件 → 应用软件 → 用户 ↑ 越靠下越"底层"，越靠近硬件
这条层次链能直接答三个判断：①OS 是最基本的系统软件（对）；②OS 属于应用软件（错）；③应用软件可以直接控制硬件（错，必须通过 OS）。
③

操作系统的发展与分类

★只考"顺序"和"分时/实时的区别"
阶段特征解决的问题
手工操作用户独占机器，人工装纸带/插线效率极低，CPU 大量空闲
批处理把一批作业交给系统，由系统自动依次执行（单道 → 多道）减少人工干预，提高 CPU 利用率（多道可"重叠"运行）
分时把 CPU 时间切成时间片，轮流分给多个终端用户实现多用户交互，每人都觉得"独占"
实时在严格的时间限制内响应外部事件用于工业控制、军事、医疗等"来不及就出事"的场景
网络 / 分布式 / 个人 / 移动联网共享资源；多台机器协同；PC 与手机普及资源共享、可靠性、便携
分时 vs 实时，一句话分清：分时是"大家轮流用，人人有份"（追求公平与交互）；实时是"必须马上响应"（追求时限与可靠）。题目里出现"时间片"→分时；出现"限时响应/工业控制"→实时。
分类角度类型
按功能/用途批处理 OS、分时 OS、实时 OS
按用户数单用户 OS、多用户 OS
按任务数单任务 OS、多任务 OS
按硬件/场景网络 OS、分布式 OS、嵌入式 OS、移动 OS
④

操作系统的五大功能（按四川考纲记这一版）

★★★简答、多选、判断都能出；关键是"用户接口"这一项
#功能具体做什么
1处理器管理
（进程管理）		为进程分配 CPU、进行进程调度、进程的创建与撤销、处理同步与互斥。核心是"让 CPU 不停工"
2存储器管理内存的分配与回收、地址映射、内存保护、虚拟存储（内存不够时借用硬盘）
3设备管理设备的分配与回收、驱动程序的调用、缓冲技术、即插即用的识别
4文件管理文件的组织与目录管理、按名存取、读写、共享与保护、磁盘空间分配
5用户接口命令接口（命令行）、图形用户界面（窗口/图标/菜单）、程序接口（系统调用）
这里有个四川卷特有的坑：不少教材把第五项写成"作业管理"。四川考纲原文列的是"用户接口"，所以多选题若给出"作业管理"和"用户接口"两个选项，按考纲选"用户接口"。答题时以考纲为准，不要被旧教材带偏。
真题2025 · 判断 27　进程与程序是一一对应的关系。
→ 错。
程序是静态的、存放在磁盘上的指令集合；进程是程序在内存中的一次执行过程，是动态的、有生命周期的。
关系是"多对多"：同一个程序可以被多次运行，产生多个进程（如开了三个 Word 窗口）；一个进程也可以调用多个程序。所以既不是"一一对应"，也不是"程序就是进程"。
怎么答"操作系统的基本功能"这道简答（5 分）：先一句总起"操作系统是最基本的系统软件，负责管理计算机的软硬件资源并为用户提供接口"，再分五条（处理器管理、存储器管理、设备管理、文件管理、用户接口），每条后面加半句解释。总—分条—每条一句，这是四川简答的标准结构。
⑤

主流操作系统与国产 OS

★★★2025 多选第 36 题：国产操作系统
系统特点考点提示
Windows图形界面友好、易用、兼容性强、多任务；商业授权收费"Windows 是应用软件"是错的，它是 OS
Linux开源、免费；多用户多任务；稳定、安全；命令行功能强大；服务器领域主流由内核 + 发行版构成，发行版如 Ubuntu、CentOS、RedHat
Unix多用户多任务、稳定可靠，早期服务器系统Linux 的设计思想源于 Unix，但 Linux 是独立实现
macOS苹果设备专用，图形化好，类 Unix 内核只能装在苹果硬件上（正版环境）
Android移动 OS，基于 Linux 内核，开源"Android 基于 Linux"是常考的对应关系
iOS移动 OS，类 Unix，闭源，仅苹果设备与 Android 对照：一个开源一个闭源
国产 OS麒麟（银河麒麟/中标麒麟）、统信 UOS、鸿蒙 HarmonyOS这三个名字要记住，是多选的答案来源
真题2025 · 多选 36（3 分）　下列属于国产操作系统的是（　）　A. 麒麟　B. 鸿蒙　C. UOS　D. Windows
答案：ABC。Windows 是美国的商业系统，唯一的排除项。
这类题的套路：三个国产 + 一个国外，只要记住"麒麟、鸿蒙、UOS"三个名字，剩下那个自动排除。
特点对比口诀：Windows 好用、Linux 免费又稳、macOS 只认苹果、Android 开源靠 Linux、iOS 封闭、国产认麒麟鸿蒙UOS。

#内容
1软件 = 程序 + 数据 + 文档
2系统软件：操作系统、语言处理程序、数据库管理系统、服务程序；应用软件：Office、浏览器等

一、判断题（5 题）

1. 操作系统是最基本的系统软件。
正确。它管理软硬件资源并为其他软件提供运行环境。
2. 进程与程序是一一对应的。
错误。程序静态、进程动态，同一程序可产生多个进程（2025 判断 27）。
3. Linux 是开源免费的操作系统，常用作服务器系统。
正确。
4. 分时操作系统的主要目标是限时响应外部事件。
错误。那是实时系统的目标；分时靠时间片实现多用户交互。
5. 编译程序属于应用软件。
错误。语言处理程序属于系统软件。

三、简答题（2 题）

10. 简述操作系统的五大基本功能。
参考答案：操作系统是最基本的系统软件，负责管理计算机的软硬件资源并为用户提供操作接口。其基本功能包括：①处理器管理，为进程分配 CPU 并进行调度；②存储器管理，完成内存分配回收与虚拟存储；③设备管理，负责设备分配、驱动与缓冲；④文件管理，实现文件的按名存取、共享与保护；⑤用户接口，提供命令接口、图形界面与系统调用。
11. 简述 Windows 与 Linux 的主要区别。
参考答案：①授权方式：Windows 为商业软件需授权付费，Linux 开源免费；②界面：Windows 以图形界面为主、易用性强，Linux 命令行功能更强；③稳定性与安全：Linux 多用户多任务、稳定性和安全性更好，常用于服务器；④应用生态：Windows 桌面软件与游戏丰富，Linux 服务器与开发工具生态更强。
